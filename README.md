# Teknic Euchner — Cojective Website Developer Assessment

Desktop-first HTML, CSS and JavaScript implementation based on the supplied Figma package.

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

## Assets

The Figma package supplied for the assessment contained 44 exported PNG assets and one MP4 video. They are included locally under:

- `assets/images/`
- `assets/videos/`

The website uses the supplied MP4 as the hero background video and several supplied PNGs throughout the page.

## JavaScript interactions

- Mobile navigation toggle
- Active navigation section highlighting
- Product detail modal
- Escape/backdrop modal closing
- Smooth anchor navigation via CSS

There is no backend, API or database; the page is intentionally static/client-side for the assessment.
